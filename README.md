# AI Agent Project Template

Шаблон рабочей папки для проектов с ИИ-агентами: конфигурация агента,
MCP-источники, управление задачами и контекстом для быстрого возобновления работы.
Работает с любым агентом, поддерживающим конвенцию AGENTS.md (Kimi Code, Claude Code, Codex и т.п.).

## Стартовый контекст агента

Файл `AGENTS.md` в корне подхватывается агентом автоматически. Он объединяет: роль агента,
процедуру старта, жизненный цикл задачи, правила ведения контекста и ограничения.
`scripts/run.sh` собирает тот же контекст вручную для агентов без поддержки этой конвенции.

## Быстрый старт

1. Скопируй шаблон: `cp -r ai-agent-project-template my-project && cd my-project`
2. Инициализируй окружение: `bash scripts/setup.sh` (создаст структуру, `.env` и симлинки скиллов для Kimi Code)
3. Заполни `.env` и проверь: `bash scripts/health_check.sh`
4. Диктуй агенту задачу — новая задача пройдёт grill-me (интервью) и превратится
   в план (правила — в `skills/skills.md`)

## Жизненный цикл задачи

Пустой `tasks/current.md` → агент ждёт задачу от оператора → grill-me → план в `current.md` →
исполнение по шагам → каждая подзадача подтверждается оператором (агент предлагает проверки) →
завершение → архив в `tasks/archive/`, шаблон восстанавливается из `tasks/TEMPLATE.md` → цикл снова.
Новые идеи по ходу — в `tasks/backlog.md`.

## Скиллы

Скиллы — в `skills/<имя>/SKILL.md`; реестр и правила — в `skills/skills.md`.
Авто-подхват зависит от harness'а: Kimi Code читает `.kimi-code/skills/` (можно симлинком
на `skills/`), остальные — по ссылке из `AGENTS.md`. Как добавить скилл — в `skills/README.md`.

## Как возобновить работу

1. Открой `memory/context_log.md` — последняя заметка: что сделано и на чём остановились
2. Проверь `tasks/current.md` — активная задача
3. Прочитай `memory/decisions.md` — почему приняты ключевые решения
4. Запусти `bash scripts/health_check.sh`

## Структура

| Папка | Назначение |
|---|---|
| `config/` | Промты, инструменты, evals, настройки агента |
| `mcp/` | MCP-серверы и их конфигурация |
| `skills/` | Скиллы агента и реестр skills.md |
| `workspace/` | Результаты запусков агента (`runs/дата_задача/`) |
| `tasks/` | Управление задачами (current / TEMPLATE / backlog / archive) |
| `memory/` | Контекст: лог сессий, решения, глоссарий |
| `scripts/` | setup, run, health_check |
