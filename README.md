# AI Agent Project Template

Шаблон рабочей папки для проектов с ИИ-агентами: конфигурация агента,
MCP-источники, управление задачами и контекстом для быстрого возобновления работы.

## Быстрый старт

1. Заполни `.env` (скопируй из `.env.example`)
2. Проверь окружение: `bash scripts/health_check.sh`
3. Запиши первую задачу в `tasks/current.md`
4. Запусти агента: `bash scripts/run.sh`

## Как возобновить работу

1. Открой `memory/context_log.md` — последняя заметка: что сделано и на чём остановились
2. Проверь `tasks/current.md` — активная задача
3. Прочитай `memory/decisions.md` — почему приняты ключевые решения
4. Запусти `bash scripts/health_check.sh`

## Структура

| Папка | Назначение |
|---|---|
| `config/` | Промты, инструменты, evals, настройки агента |
| `mcp/` | MCP-серверы и их конфигурация |
| `workspace/` | Результаты запусков агента (`runs/дата_задача/`) |
| `tasks/` | Управление задачами (backlog / current / archive) |
| `memory/` | Контекст: лог сессий, решения, глоссарий |
| `scripts/` | setup, run, health_check |
