# Скиллы проекта

Единый реестр скиллов и правил их использования. `AGENTS.md` только ссылается
сюда — не дублируй списки скиллов и правила в других файлах.

## Правило входа в задачи

- **Новая задача** (пустой `tasks/current.md`): оператор диктует задачу → агент
  проводит `grill-me` → составляет план → оформляет `tasks/current.md`.
  Исполнение — только после подтверждения плана оператором.
- **Уточнение/продолжение идущей задачи** → без grill-me, сразу работаем.

## Реестр скиллов

| Скилл | Когда использовать |
|---|---|
| `grill-me` | Новая задача: интервью-стресс-тест плана (дерево решений, раунды вопросов с рекомендациями агента; факты агент добывает сам) |

Пути к скиллам: `skills/<имя>/SKILL.md`. Как добавить скилл — `skills/README.md`.
