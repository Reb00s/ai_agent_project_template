# Скиллы проекта

Скиллы — переиспользуемые инструкции для агента в формате `SKILL.md`
(frontmatter + тело). Лежат в `skills/<имя>/SKILL.md` и попадают в git
вместе с проектом. Реестр и правила использования — в `skills/skills.md`.

## Формат

```markdown
---
name: my-skill
description: Когда агент должен его использовать (это видит модель).
---

<инструкции для агента: шаги, формат, границы>
```

- `description` решает, предложит ли агент скилл сам — пиши её под триггеры.
- Для скиллов-интервью и «опасных» режимов укажи в теле, кто запускает скилл.
  Флаг `disable-model-invocation: true` понимает только Kimi Code — остальные
  harness'ы читают правило из текста.

## Как добавить скилл

1. Создай `skills/<имя>/SKILL.md` по формату выше.
2. Добавь строку в реестр `skills/skills.md`.
3. Проверь: `bash scripts/health_check.sh` валидирует реестр и папки скиллов.

## Поддержка harness'ов

- **Kimi Code**: авто-подхватывает скиллы из `.kimi-code/skills/`. `scripts/setup.sh`
  создаёт эту папку с симлинками на `skills/*` автоматически; симлинки не коммитятся
  (в `.gitignore`) и пересоздаются при развёртывании шаблона.
- **Claude Code / Codex / прочие**: агент читает `skills/skills.md` по ссылке
  из `AGENTS.md` и открывает нужный `SKILL.md` сам.
