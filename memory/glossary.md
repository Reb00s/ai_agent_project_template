# Глоссарий проекта

| Термин / имя | Значение | Где используется |
|---|---|---|
| grill-me | Скилл-интервью: стресс-тест плана через раунды вопросов (дерево решений) | `skills/grill-me/SKILL.md`, правило входа в новые задачи — `skills/skills.md` |
| скилл (skill) | Переиспользуемая инструкция для агента в формате SKILL.md (frontmatter + тело) | `skills/<имя>/SKILL.md` |
| skills.md | Реестр скиллов и правил их использования; AGENTS.md только ссылается на него | `skills/skills.md` |
| context_log | Лог сессий: заметка в конце каждой сессии для возобновления за <2 минуты | `memory/context_log.md` |
| MCP | Model Context Protocol — внешние источники данных/инструменты агента | `mcp/mcp_config.json` |
| eval | Тестовый вход с ожидаемым результатом для проверки агента до боевого запуска | `config/evals/` |
