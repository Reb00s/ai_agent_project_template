- **Архитектура веб-аналога (согласовано с оператором 2026-10-19):**
  - Стек: **Django + PostgreSQL**, Docker Compose, монолит; фазы: 1 каркас+инсталлятор+мастер первого запуска → 2 ядро (субъекты/инциденты/атрибуты/файлы) → 3 процессы (указания/согласования/статистика) → 4 синхронизация филиалов
  - Инцидент = единая сущность (экон.+ИБ), даты обнаружения/закрытия, связи много-ко-многим к субъектам (с ролью) и другим инцидентам
  - Субъекты универсальные: тип — справочник (ФЛ/ЮЛ/Здание/…), атрибуты по типу
  - Настраиваемые атрибуты: шаблоны (имя/тип/кому/обязательность/флаг «историчный»); шаблон неизменяем после появления данных; удаление шаблона → в карточке заметка «атрибут не редактируется, шаблон удалён — обратитесь к администратору»; значения в JSONB
  - Указания: задача руководитель→исполнитель; подчинённость многие-ко-многим (у подчинённого несколько руководителей); цикл: создано→в работе→выполнено→принято/возвращено; привязка к инциденту/субъекту/без
  - Доступ: пользователь = филиал (дерево) + уровень секретности; уровень = набор включаемых уровней (настраивается; по умолчанию все нижние); запись ур.1 видна всем филиалам, ур.>1 — своей ветке + по набору уровней; проверка прав только на сервере
  - Установка: install.sh ставит Docker+систему, всё конфигурируется мастером первого запуска (админ, филиалы, уровни, типы субъектов, дерево подчинённости)
